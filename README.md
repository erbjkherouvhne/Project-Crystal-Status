# Project Crystal

## About
Project Crystal is a community-driven Fortnite Online Gameserver (OGFN) project focused on bringing back the classic Fortnite experience, starting with **Chapter 2 Season 5**.

Our goal is to recreate the nostalgia of Fortnite's golden era while building a stable, feature-rich experience with custom infrastructure, dedicated services, and continuous development.

## Development
After months of development, testing, and deployment, we've officially chosen Chapter 2 Season 5 as the foundation for Project Crystal. We've been working hard behind the scenes to bring everything together and get the project ready for release.

## Features
- Custom-built backend infrastructure
- Dedicated Project Crystal launcher
- Chapter 2 Season 5 support
- Custom game server development
- Matchmaking and game functionality
- Locker and cosmetic systems
- Future custom cosmetics and exclusive features
- Continuous updates and improvements

## Current Progress

## Release Plans
Our initial release will focus on delivering a stable and authentic Chapter 2 Season 5 experience. Custom cosmetics will not be included at launch, but we may introduce them in future updates once the project is established.

We're committed to making Project Crystal an enjoyable experience for everyone who wants to revisit this iconic season.
